# 意图裁决契约（一页规范）· 2026-11-21

> 目的：让**任何第三方**照着这页就能写出第二实现，并用 12 条公开用例自检；不依赖我们的代码。
> 本规范描述"风险判定"，**判定 ≠ 授权**。判定结果不得直接当作放行凭据。

## 1. 输出取值

| 取值 | 含义 | 是否可放行 |
|---|---|---|
| `ALLOW` | 未发现触达策略的能力组合 | 可继续走授权流程（不等于已授权） |
| `REVIEW` | 命中需人工确认的能力面（提权、持久化、凭据访问、时间篡改、文档描述危险链） | 否，必须人工 |
| `DENY` | 命中代码中**真实发生**的危险能力组合（外泄链、下载即执行、破坏、关闭防护、远程导入） | 否 |
| `UNKNOWN` | 输入不可读、解析失败、策略缺失、引擎异常 | **否（fail-closed）** |
| `PROMPT_ONLY` | 无任何可执行代码文件，风险面仅剩提示注入（由规则层负责） | 否，交由提示层判定 |

`PROMPT_ONLY` 是"无代码"这一输入形态的显式结论，**不是**第五种授权状态；调用方不得把它映射成 ALLOW。
枚举之外的任何取值一律按 `UNKNOWN` 处理。

## 2. 判定优先级

`DENY` > `REVIEW` > `PROMPT_ONLY` > `ALLOW`；`UNKNOWN` 可覆盖以上全部（输入不可判定时优先）。
同一输入若同时命中 DENY 与 REVIEW，返回 DENY，并在 `policy_hits` 里保留全部命中项（便于复核），不得只留最高级。

## 3. 输入与"行为"的边界

1. 只看**可执行代码**文件（`.py .sh .js .ts .mjs .cjs .ps1 .bat .cmd` 等）里的行为。
2. 注释（`#`、`//`、`*`、`<!--`）不是行为，不得计为能力。
3. 规则定义处的原始字符串（`r"..."`）与 `re.compile(...)` 是"检测器自身"，不得计为能力（检测器悖论）。
4. 文档（`.md .txt .rst`）里出现的能力描述**最高只到 `REVIEW`**，永不 `DENY`。
5. **即使没有任何代码文件，也必须评估文档能力**：文档描述外泄/下载执行/破坏链时返回 `REVIEW`，而不是直接 `PROMPT_ONLY`。
6. 解释器执行脚本（`bash x.sh`、`sh x.sh`、`python x.py`）视为动态执行，不得只认管道（`curl ... | bash`）与 `sh -i`。

## 4. 能力到裁决的映射（最小集）

| 能力组合 | 裁决 | 理由 |
|---|---|---|
| 读凭据 + 网络外发 | DENY | 完整外泄链 |
| 下载 + 动态执行 | DENY | 远端代码执行 |
| 混淆解码 + 动态执行 | DENY | 绕过静态检查 |
| 破坏性操作（`rm -rf /etc`、`mkfs`、`dd if=`） | DENY | 不可恢复 |
| 持久化 + 外连 | DENY | 后门常驻 |
| 关闭/削弱主机防护 | DENY | 安全基线破坏 |
| 下载 + 执行二进制 | DENY | 投放链 |
| 远程 URL 直接导入/加载 | DENY | 不可审计代码 |
| 仅提权 / 仅持久化 / 仅凭据访问 / 仅时间篡改 | REVIEW | 需人工确认必要性 |
| 文档描述以上任意危险链 | REVIEW | 描述≠行为，但不能放过 |

## 5. 与外部系统的映射（供集成方参考，不承诺兼容）

| HTTP / 策略引擎 | 本契约取值 |
|---|---|
| 200 + 放行 | ALLOW（仍须走授权） |
| 202 / 人工工单 | REVIEW |
| 403 | DENY |
| 5xx / 超时 / 无法解析 | UNKNOWN（按 403 处理） |
